## About

<div align="center">

[![Status](https://readme-typing-svg.demolab.com?font=Fira+Code&weight=500&size=16&duration=3200&pause=1000&color=14B8A6&center=true&vCenter=true&width=680&lines=Building+full-stack+web+apps+with+Next.js+and+FastAPI;Learning+something+new+in+every+project)](https://git.io/typing-svg)

</div>

Web developer from Portmore, Jamaica, studying Computer Science at the University of Technology, Jamaica (UTech).

I build full-stack web apps: React and Next.js frontends, Python and Node backends, and the APIs, bots and small tools that connect them. I have built and maintained websites for real businesses, which taught me to care about things that are easy to skip in coursework, like page speed, accessibility, deployments and code other people can pick up.

I am looking for junior developer and internship roles.
